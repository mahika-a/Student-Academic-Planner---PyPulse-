# Project Requirements

## 1. Functional Requirements

### 1.1 Syllabus and Progress

- The system shall allow the user to enter subject names.
- The system shall allow the user to enter progress percentages.
- The system shall display subject-wise progress.

### 1.2 Exams and Results

- The system shall allow the user to enter marks obtained.
- The system shall allow the user to enter total marks.
- The system shall calculate and display the percentage.

### 1.3 Calendar and Events

- The system shall allow the user to enter academic events.
- The system shall display the entered event information.

### 1.4 To-Do

- The system shall allow the user to enter academic tasks.
- The system shall display the entered tasks.

### 1.5 Study Planner

- The system shall allow the user to enter study planning information.
- The system shall display the entered study plan.

### 1.6 Deadline Tracker

- The system shall allow the user to enter academic deadlines.
- The system shall display the entered deadline information.

### 1.7 Performance Insight

- The system shall use subject progress information.
- The system shall classify progress into basic performance categories.
- The system shall display the corresponding performance insight.

### 1.8 Main Menu

- The system shall provide a menu for accessing the available features.
- The system shall allow the user to select a feature.
- The system shall provide an option to exit the application.


## 2. Non-Functional Requirements

### 2.1 Usability

- The application shall provide a simple menu-driven interface.
- Instructions and prompts shall be easy for the user to understand.

### 2.2 Performance

- The application shall process normal user inputs without unnecessary delay.
- Calculations and basic operations shall be performed quickly.

### 2.3 Reliability

- Each feature shall work according to its intended function.
- The application shall continue to operate correctly when valid inputs are provided.

### 2.4 Maintainability

- The application shall use separate Python files for different features.
- Functions shall be used to keep the code organized and easier to modify.

### 2.5 Resource Efficiency

- The application shall use basic Python features and standard modules.
- The application shall not require large external resources to run.

### 2.6 Error Handling

- The application shall handle invalid menu choices appropriately.
- User input shall be checked where necessary to reduce input-related errors.
