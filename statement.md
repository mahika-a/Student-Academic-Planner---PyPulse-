# Academic Tracker and Study Planner - PyPulse

## 1. Problem Statement

Students often need to manage multiple academic activities such as subject progress, exam results, study plans, tasks, events, and deadlines. Managing these activities separately can make it difficult to keep track of academic responsibilities.

The Academic Tracker and Study Planner provides a simple console-based solution that brings these academic activities together in one Python application.

---

## 2. Objectives

The main objectives of the Academic Tracker and Study Planner are:

- To provide a simple application for managing common academic activities.
- To help students track their subject-wise academic progress.
- To provide a simple way to calculate examination percentages.
- To help students organize tasks, events, study plans, and deadlines.
- To provide basic performance insights based on subject progress.
- To apply Python programming concepts to a practical real-world problem.
- To develop the application using a modular and organized structure.

## 3. Scope of the Project

The project focuses on basic academic planning and tracking.

The application allows the user to:

- Track subject progress.
- Calculate exam result percentages.
- Manage academic events.
- Manage to-do tasks.
- Create study plans.
- Track academic deadlines.
- View basic performance insights.

The current version is designed as a simple console-based application and does not include permanent data storage or a graphical user interface.

---

## 4. Target Users

The main target users are:

- College students.
- Students who want to organize their academic activities.
- Students who want a simple way to track progress, tasks, study plans, and deadlines.

---

## 5. High-Level Features

### 5.1 Syllabus and Progress

- Allows users to enter subjects.
- Records the progress percentage of each subject.
- Displays subject-wise progress.

### 5.2 Exams and Results

- Allows users to enter marks obtained and total marks.
- Calculates the percentage.

### 5.3 Calendar and Events

- Allows users to record academic events.

### 5.4 To-Do

- Allows users to create and manage academic tasks.

### 5.5 Study Planner

- Allows users to enter and organize study planning information.

### 5.6 Deadline Tracker

- Allows users to record and manage academic deadlines.

### 5.7 Performance Insight

- Uses subject progress information.
- Provides a basic status based on the entered progress percentage.
